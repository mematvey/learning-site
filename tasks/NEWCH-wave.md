# Волна NEWCH: 32 новые главы, графы связей, карта сайта, маршруты

На `main` уже лежат **заготовки** всех 32 глав: `content/<topic>/<slug>/index.svx` (frontmatter с `prereqs`, `labs`, один абзац-заглушка), `src/lib/components/demos/<Demo>.svelte` (заглушка «Демо в разработке») и `labs/<topic>-<slug>/` (пустые файлы). Id глав, демо и лабов зафиксированы, менять нельзя. Твой пакет заменяет заглушку своей роли настоящим содержимым.

## Общие правила (для всех пакетов)
- Работаешь **только в своём worktree** (абсолютный путь в задании), ветка `task/<id>`. Каждая команда начинается с `cd <worktree> &&` (у параллельных агентов общий шелл). Windows, Git Bash, Python только через `uv`.
- `node_modules` в worktree это junction на общий каталог. **Не запускай `npm ci`/`npm install`, не удаляй и не меняй `node_modules`.**
- Читай первым: `CLAUDE.md`, `docs/CONTENT-GUIDE.md`, `docs/design-system.md`, `docs/ARCHITECTURE.md` (по необходимости). Образцы: глава `content/dl/softmax/`, `content/classic-ml/linear-regression/`; демо `src/lib/components/demos/LayerNormDemo.svelte` + `src/lib/demos/layer-norm.ts`; лаб `labs/dl-softmax/`.
- Владеешь только файлами своей роли (ниже). Запрещено: `package.json`, lock, корневые конфиги, `src/routes/**`, `src/lib/contracts/**`, `docs/**`, `tasks/**`, `.claude/**`, чужие главы, демо и лабы. Не хватает общего типа или компонента: опиши в отчёте, не правь.
- Язык: контент на русском, английский термин при первом упоминании; код, идентификаторы и комментарии в коде на английском. Только существующие токены и компоненты (`docs/design-system.md`), обе темы, ширина 375px без горизонтального скролла, `prefers-reduced-motion`, клавиатура.
- Факты и числа только проверяемые, с источником (реальный `url`). Не выдумывай ссылки, цитаты и числа. Нет уверенности: формулируй качественно.
- Бюджет ~100–140k токенов, до ~600 строк. Упёрся в бюджет при большом остатке: остановись и верни `partial` со списком готового. Осталось 10–20k: доделай.
- **Коммит один, ровно сообщение из пакета, без `Co-Authored-By`, без упоминаний агентов, ИИ, Claude и моделей.** Не пушь, не сливай, оркестратор сливает сам. Отчёт по `tasks/REPORT-TEMPLATE.md`, до 200 слов: файлы, выполненные команды с результатом, открытые вопросы.

## Роли

### TEXT: текст главы
Владеешь: `content/<topic>/<slug>/index.svx`, `data/glossary/<topic>-<slug>.yaml`. Не трогай `labs:` и `prereqs:` во frontmatter, кроме случая, когда пререквизит неверен по смыслу (опиши в отчёте).
- Полная глава по скелету `CONTENT-GUIDE` (Идея, Интуиция, Математика, Код, Частые ошибки, Проверь себя, Источники), уровни сложности и глубины (`<Level>`, `<Variant>`), id блоков, `<Quiz>` 2–4 вопроса, `<Cite>` и `sources` с `url`.
- Демо вставляй как `<ИмяДемо />` (компонент уже существует как заглушка и подменится настоящим). Что демо показывает, смотри в таблице ниже, ссылайся на это в тексте и добавь «Что заметить». Лаб, если он есть, вставляй как `<CodeLab lab="<topic>-<slug>" />` в разделе «Код»; в тексте опиши задачу лаба по таблице.
- Новые понятия: в `concepts` и в `data/glossary/<topic>-<slug>.yaml` (формат как в `data/glossary/dl-softmax.yaml`). Id терминов уникальны на весь сайт: перед добавлением проверь `grep -r "id: <term>" data/glossary`.
- Ссылаться на понятия из глав, которых ещё нет, нельзя. Допустимо ссылаться только на пререквизиты и на существующие главы.
- Проверка: `npm run check:content`, `npx prettier --check content data`, затем один раз `npm run build` (должен собраться).

### DEMO: интерактив
Владеешь: `src/lib/components/demos/<Demo>.svelte` (замени заглушку), `src/lib/demos/<slug>.ts` (чистая логика без DOM) и `src/lib/demos/<slug>.test.ts`.
- Только Svelte 5 (runes) + SVG/D3 в стиле существующих демо. Подключение к контексту демо (`DEMOS_CONTEXT`, `HIGHLIGHT_CONTEXT`) как в `LayerNormDemo`. Состояние снаружи через `initial`.
- Слайдеры и кнопки с подписями, текстовое описание состояния (aria-live), блок «Что заметить», сброс к исходным значениям. Цвета только токены (`--topic`, `--cat-*`).
- Тесты Vitest на логику (`src/lib/demos/<slug>.test.ts`): ключевые вычисления, граничные значения, детерминизм при заданном seed.
- Проверка: `npx vitest run src/lib/demos/<slug>.test.ts`, `npx svelte-check --tsconfig ./tsconfig.json`, `npx eslint src/lib/demos src/lib/components/demos/<Demo>.svelte`, `npx prettier --check` для своих файлов.

### LAB: лаб
Владеешь: `labs/<topic>-<slug>/` целиком. Процедура: `.claude/skills/new-lab/SKILL.md` (для Compute вариант из раздела «Варианты»: ядро CUDA/Triton не запускается в браузере, используй симулятор или предрасчёт).
- `lab.yaml` (id, chapter, runtime, packages только из разрешённых в `scripts/lab_check.py`), `starter.py` (с `TODO`), `solution.py`, `tests_visible.py`, `tests_hidden.py`. Эталон проходит все тесты, старт падает хотя бы на одном. Задание лаба описано в таблице ниже.
- Проверка: `uv run python scripts/lab_check.py <topic>-<slug>` (ожидается успех), `uv run ruff check labs/<topic>-<slug>` и `uv run ruff format --check labs/<topic>-<slug>`.

## Таблица глав

Формат: id главы; демо (что показывает); лаб (задача лаба).

### Classic ML
- `classic-ml/regularization`; `RegularizationDemo`: полином на облаке точек, слайдеры степени и λ, переключатель L1/L2, график весов; лаб: ridge в замкнутой форме и lasso (soft-thresholding, координатный спуск) на NumPy.
- `classic-ml/decision-trees`; `DecisionTreeDemo`: точки двух классов, дерево растёт по шагам, разбиение плоскости и график Джини/энтропии, слайдер глубины; лаб: функция лучшего разбиения по Джини и рекурсивное дерево.
- `classic-ml/ensembles`; `EnsembleDemo`: сравнение одного дерева, случайного леса (число деревьев) и бустинга (число итераций) на границе решения; лаб: бэггинг деревьев-пней и градиентный бустинг для регрессии.
- `classic-ml/knn-svm`; `KnnSvmDemo`: переключатель kNN/SVM, граница решения при смене k, C и ядра, опорные векторы подсвечены; лаб: kNN-классификатор с весами по расстоянию.
- `classic-ml/clustering-pca`; `ClusteringPcaDemo`: k-means по шагам (центры, назначения) и проекция PCA на главные оси с долей объяснённой дисперсии; лаб: k-means и PCA через SVD.
- `classic-ml/metrics-validation`; `MetricsDemo`: порог классификации, матрица ошибок, precision/recall/F1, ROC и PR-кривые двигаются слайдером; лаб: метрики по матрице ошибок и ROC-AUC.

### DL Theory
- `dl/backprop`; `BackpropDemo`: маленький граф вычислений, шаги прямого и обратного прохода с числами на рёбрах; лаб: обратный проход для двухслойной сети на NumPy с проверкой численным градиентом.
- `dl/optimizers`; `OptimizerDemo`: поверхность потерь (контуры), траектории SGD/momentum/Adam с общими стартом и шагом; лаб: SGD, momentum и Adam как функции обновления.
- `dl/activations-init`; `ActivationInitDemo`: графики активаций и их производных, гистограммы активаций по слоям при разных инициализациях (Xavier, He); лаб: инициализации и прямой проход, статистика активаций по слоям.
- `dl/positional-encoding`; `PositionalEncodingDemo`: тепловая карта синусоидальных кодирований и вращение пар компонент (RoPE); лаб: синусоидальное кодирование и применение RoPE.
- `dl/transformer-block`; `TransformerBlockDemo`: схема блока со стрелками остаточных связей, нажатие на узел показывает форму тензора и операцию; лаб: сборка блока из готовых функций внимания, нормализации и MLP.
- `dl/regularization-dl`; `DropoutDemo`: слой нейронов с маской dropout, кривые обучения и валидации при weight decay и ранней остановке; лаб: inverted dropout и weight decay в шаге обучения.

### Статистика
- `stats/classical-probability-2`; `BayesDemo`: дерево вероятностей и «частотные ящики» (100 человек) для формулы Байеса, слайдеры распространённости, чувствительности, специфичности. Лаба нет, но добавь **задачи в стиле `stats/classical-probability`**: компоненты `Prob<N>` не нужны, достаточно 4–5 задач с параметрами через общие компоненты `src/lib/components/problems/` (если нужна новая задача, опиши в отчёте, DEMO-пакет создаёт `ProbBayes1…`).
- `stats/random-variables`; `RandomVariableDemo`: распределение дискретной величины (кубик, сумма), ожидание и дисперсия, столбцы редактируются мышью. Лаба нет.
- `stats/distributions`; `DistributionsDemo`: PMF/PDF биномиального, Пуассона, нормального, слайдеры параметров, заливка вероятности отрезка; лаб: PMF/PDF и выборка из распределений по обратной функции.
- `stats/limit-theorems`; `LimitTheoremsDemo`: сходимость среднего (закон больших чисел) и гистограмма сумм/средних n величин, приближающаяся к нормальной кривой; лаб: симуляция ЦПТ и оценка ошибки.
- `stats/estimation-testing`; `HypothesisTestDemo`: доверительные интервалы в многократном повторении (доля, накрывшая среднее) и проверка гипотезы с ошибками I и II рода, слайдеры n, α, эффект; лаб: доверительный интервал и z/t-критерий.

### MLOps Practices
- `mlops/data-versioning`; `DataVersioningDemo`: граф коммитов данных и кода, выбор версии показывает хеши и воспроизводимость эксперимента. Лаба нет.
- `mlops/experiment-tracking`; `ExperimentTrackingDemo`: таблица запусков, сортировка и сравнение метрик, параллельные координаты параметров; лаб: простой трекер запусков (запись параметров и метрик, поиск лучшего) на чистом Python.
- `mlops/pipelines-ci`; `PipelineDemo`: DAG пайплайна, запуск по шагам, падение шага блокирует выкладку, кеш шагов. Лаба нет.
- `mlops/serving`; `ServingDemo`: сравнение пакетного и онлайн-инференса, канареечная выкладка слайдером доли трафика и откат. Лаба нет.
- `mlops/monitoring-drift`; `DriftDemo`: два распределения, сдвиг слайдером, PSI и KS-статистика меняются, порог тревоги; лаб: PSI и статистика Колмогорова–Смирнова на NumPy.

### CompScience
- `cs/complexity`; `ComplexityDemo`: графики роста n, n log n, n², 2ⁿ, слайдер n и константы, точка пересечения. Лаба нет.
- `cs/sorting-searching`; `SortingDemo`: пошаговая анимация сортировок (пузырёк, вставки, слияние, быстрая) со счётчиком сравнений, бинарный поиск; лаб: слияние двух отсортированных списков, merge sort и бинарный поиск.
- `cs/hash-tables`; `HashTableDemo`: вставка ключей, коллизии (цепочки/открытая адресация), коэффициент заполнения, перехеширование; лаб: хеш-таблица с цепочками.
- `cs/graphs-algorithms`; `GraphAlgoDemo`: редактируемый граф, BFS/DFS/Дейкстра по шагам с очередью/стеком; лаб: BFS и Дейкстра на списках смежности.
- `cs/memory-cache`; `CacheDemo`: сетка массива, обход по строкам и по столбцам, промахи кэша и оценка времени, размер линии кэша слайдером. Лаба нет.

### Compute
- `compute/gpu-architecture`; `GpuArchitectureDemo`: схема SM, варпов и иерархии памяти с задержками, нажатие на узел показывает числа с источником. Лаба нет.
- `compute/cuda-basics`; `CudaGridDemo`: сетка блоков и потоков, `blockIdx`/`threadIdx` и вычисление глобального индекса, ввод размеров; лаб: симулятор индексации (вычислить индексы потоков и граничную проверку) на чистом Python.
- `compute/memory-coalescing`; `CoalescingDemo`: варп обращается к памяти с шагом, показаны транзакции и доля полезных байт. Лаба нет.
- `compute/triton-intro`; `TritonDemo`: разбиение вектора на блоки программы Triton, маска на хвосте; лаб: симулятор блочного сложения векторов с маской (чистый Python).
- `compute/matmul-optimization`; `MatmulTilingDemo`: тайлы матриц, сколько раз каждый элемент читается из глобальной памяти при разных размерах тайла. Лаба нет.

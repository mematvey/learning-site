# Волна M: статический макет для согласования дизайна

Общий контракт: `docs/mockups/CONTRACT.md`. Дизайн-принципы и токены: `docs/design-system.md`. Все файлы в `docs/mockups/`.

Бюджет каждого пакета: до ~100k токенов, до ~600 строк. Упёрся в бюджет с большим остатком работы: остановись и верни частичный результат. Осталось 10–20k: доделай.

Критерии приёмки для всех: страница открывается через `file://` без ошибок в консоли; скриншоты обеих тем сняты `shoot.py` и просмотрены тобой; нет «сырых» hex вне `tokens.css`; изменены только твои файлы; работа закоммичена в твоей ветке.

Отчёт (до 200 слов): изменённые файлы; выполненные команды и результат; что осталось или вызывает сомнение.

## M1. Страница главы (`chapter.html`, `chapter.css`)

Глава «Scaled dot-product attention», топик DL Theory (`data-topic="dl"`).

1. **Шапка** (липкая, тонкая): логотип-текст «learning-site», хлебные крошки «DL Theory › Трансформеры › Attention», поле поиска (заглушка, ⌘K), индикатор прогресса главы (тонкая полоса цвета `--topic` под шапкой, растёт при скролле), кнопка темы (солнце/луна, inline SVG).
2. **Панель уровней** под шапкой: два слайдера «Сложность» (Интуиция / Основа / Формально / Исследователь) и «Глубина» (Идея / Реализация / Железо), подписи положений под слайдером. При изменении появляется кнопка «Применить» (до этого скрыта). По нажатию текст меняется: блоки `[data-c-min]`, `[data-d-min]` показываются, если уровень ≥ порога; блоки `[data-c-only="1"]` / `[data-c-only="2-4"]` это замены (вариант гибридного подхода). Уровни пишутся в URL (`?c=2&d=1`). Небольшой бейдж у блоков глубины «⚙ Железо».
3. **Заголовок главы**: H1, подзаголовок в одно предложение, мета-строка (≈ 25 мин, 1 лаб, чипы пререквизитов «Скалярное произведение», «Softmax»), кнопка «Отметить пройденным» (контурная, без звёзд).
4. **Раскладка**: слева оглавление (липкое, подсветка текущего раздела), центр колонка текста `--text-width`, справа поля для заметок. Широкие рисунки (`#attention-demo`) занимают `--wide-width`.
5. **Текст** по скелету: Идея → Интуиция → Математика → Код → Частые ошибки → Проверь себя. Пиши содержательно и сжато (это реальный текст, а не lorem ipsum). Используй:
   - замены: `data-c-only="1"` (аналогия с поиском: запрос, ключи, значения) и `data-c-only="2-4"` (формальное определение через $\alpha_{ij}$);
   - слой `data-c-min="3"`: вывод, почему $\mathrm{Var}(q\cdot k)=d$ и softmax насыщается;
   - слой `data-d-min="3"`: память $O(n^2)$ в HBM, идея FlashAttention (тайлы в SRAM, online softmax);
   - слова-сущности `<span class="ent ent-q">запрос Q</span>` и т.д., с подсветкой при наведении (контракт);
   - ссылки `.demo-link` «посмотрите, что будет без масштаба» и «выберите токен „кот“ запросом»;
   - термин глоссария `<abbr class="term" data-def="...">softmax</abbr>` с подсказкой при наведении;
   - врезка «Осторожно» (`--warn`, `--warn-bg`): забыли маску в декодере / делят на $d$ вместо $\sqrt d$;
   - сворачиваемое отступление `<details>` «Почему именно √d, а не d?»;
   - блок «Проверь себя»: 2 вопроса, ответ раскрывается по клику, без оценок.
6. **Заметки**: одна готовая заметка на полях напротив абзаца (подсвеченная цитата в тексте + карточка справа: текст заметки, тег, статус `open`). При выделении текста появляется плавающая кнопка «💬 Заметка» (без сохранения).
7. **Подвал главы**: «Источники» (Vaswani et al. 2017; Dao et al. 2022), предыдущая/следующая глава.

Контейнеры `#attention-demo`, `#steps-demo`, `#lab-demo` вставь в разделы Интуиция, Математика, Код соответственно. Виджеты пишут другие пакеты; на время работы оставь контейнеры пустыми (min-height с пунктирной рамкой допустим только если файл виджета не найден: проверяй `window.attentionDemo` и т.д. не нужно, просто оставь контейнер).

## M2. Демо внимания (`attention-demo.*`)

Широкий рисунок для раздела «Интуиция».

- Предложение из 6 токенов: «кот сел на коврик потому что» (или похожее осмысленное), токены в виде чипов.
- Выбранный токен-запрос (клик по чипу) выделен `--cat-1`. От него к остальным токенам дуги (SVG), толщина и прозрачность ∝ весу внимания.
- Рядом тепловая карта 6×6 весов (строки: запросы Q, столбцы: ключи K), шкала `--seq-0` → `--seq-1`, значения в ячейках. Строка текущего запроса обведена. Наведение на ячейку показывает подсказку `α = 0.31` и подсвечивает пару токенов.
- Переключатель «Масштаб 1/√d: вкл/выкл» и слайдер «d» (4…256). Веса пересчитываются в JS из фиксированных псевдо-случайных векторов (seeded PRNG), видно, что без масштаба при большом d распределение становится почти one-hot.
- Плавные переходы (`--dur`), без анимации при `prefers-reduced-motion`.
- Подпись рисунка: «Рис. 1. ...» + строка «Что заметить: ...». Текстовая альтернатива в `<details>` («Описание рисунка»).
- `window.attentionDemo.set({scaled, query})` по контракту. Реакция на `body[data-hl="q|k|v"]`: подсветка строк/столбцов карты.

## M3. Пошаговые карточки (`steps-demo.*`)

Компонент StepCards для раздела «Математика». 4 шага: (1) $S = QK^\top$, (2) $S/\sqrt{d}$, (3) $A = \mathrm{softmax}(S)$ по строкам, (4) $O = AV$.

- Слева карточка шага: номер «Шаг 2 из 4», заголовок, 2–3 предложения, формула (KaTeX, рендер через `katex.render`, если `window.katex` есть; иначе текст), кнопки «Назад» / «Далее» и точки-индикатор.
- Справа схема матриц (SVG): прямоугольники Q (n×d, `--cat-1`), Kᵀ, V, S, A, O с подписями размеров; на текущем шаге участвующие матрицы яркие, остальные приглушены; переход плавный.
- Клавиши ← → переключают шаги, когда компонент в фокусе.
- Подпись «Рис. 2».

## M4. Лаб с кодом (`lab-demo.*`)

Компонент CodeLab для раздела «Код». Без реального выполнения: показываем вид.

- Шапка блока: «Лаб: реализуйте attention на NumPy», бейдж «Python · Pyodide», кнопки «Сбросить», «▶ Запустить» (основная), подсказка `Ctrl+Enter`.
- Редактор: моноширинный, нумерация строк, простая подсветка синтаксиса Python (ключевые слова, строки, числа, комментарии) своим кодом; `contenteditable` или textarea поверх `pre`. Стартовый код: функция `attention(Q, K, V, mask=None)` с `# TODO`.
- По «Запустить»: индикатор «Выполняется… 0.4 с» → панель результата (`LabResult`):
  - сводка «3 из 4 тестов прошли» (`--ok` / `--fail`);
  - список тестов; упавший раскрыт: «test_scaling: ожидалось max|Δ| < 1e-6, получено 0.083», маленькая таблица ожидаемое/полученное;
  - график (SVG): «распределение весов по строке» ожидаемое vs ваше, в стиле сайта;
  - время выполнения.
- Второе нажатие показывает все тесты зелёными (имитация исправления), чтобы было видно оба состояния; на скриншоте показывай состояние с одной ошибкой (рендерить его сразу при загрузке, если в URL есть `?lab=result`; `chapter.html` скриншотится без параметра, поэтому по умолчанию тоже покажи результат с одной ошибкой).
- Строка «Черновик сохранён · 2 мин назад».

# Шаблон отчёта по пакету

До 200 слов. Только факты, без пересказа задания.

```
Пакет: <id>
Статус: done | partial | failed
Ветка / коммит: <branch> <short-sha>

Изменённые файлы:
- <path> — <что сделано, 3–8 слов>

Команды и результаты:
- `<команда>` → <ok / N ошибок, ключевая строка вывода>

Открытые вопросы:
- <вопрос или «нет»>

Осталось (только для partial/failed):
- <что не сделано и почему>
```

Правила:
- Команды из критериев приёмки пакета запускаются все; результат пишется честно, включая падения.
- Если что-то не проверено, так и написать («не проверено: …»).
- Не предлагать расширять задачу; новые заботы оформлять как «открытый вопрос».

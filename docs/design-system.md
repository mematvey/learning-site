# Дизайн-система

Черновик после изучения референсов. Токены и компоненты уточняются в вертикальном срезе. Всё пишем сами: файлы, шрифты и вёрстку референсов не копируем.

## 2. Принципы

1. **Воздух.** Колонка текста 680–720px, большие вертикальные отступы между секциями, рисунки шире текста (до 1100px).
2. **Цвет несёт смысл.** Каждая сущность главы (например, Q, K, V) получает цвет из категориальной палитры и сохраняет его в тексте, формулах и графиках.
3. **Обзор → детали.** Сначала схема целиком, затем раскрытие частей. Детали не загромождают основной поток: сворачиваются или открываются по клику.
4. **Интерактив только по делу.** Каждый интерактив имеет подпись (что крутить и что заметить) и текстовую альтернативу.
5. **Спокойное движение.** Переходы 150–300 мс, ease-out. При `prefers-reduced-motion: reduce` переходы мгновенные, скролл-анимации заменяются статичными состояниями.
6. **Тёмная тема равноправна.** Все цвета задаются токенами; тёмная тема проверяется скриншотами design-qa так же, как светлая.

## 3. Токены (CSS custom properties)

Источник истины: `src/lib/theme/tokens.css`. Tailwind читает их через `theme.extend.colors` (`bg-surface`, `text-muted` и т.д.).

### Цвета

| Токен | Светлая | Тёмная | Назначение |
|---|---|---|---|
| `--bg` | `#fbfbfa` | `#0f1115` | фон страницы |
| `--surface` | `#ffffff` | `#171a21` | карточки, панели |
| `--surface-2` | `#f3f4f6` | `#1f232c` | вложенные блоки, код |
| `--border` | `#e5e7eb` | `#2a2f3a` | линии |
| `--text` | `#1a1d23` | `#e6e8ec` | основной текст |
| `--text-muted` | `#5b6270` | `#9aa3b2` | подписи, метаданные |
| `--accent` | `#2563eb` | `#7aa2ff` | ссылки, активные контролы |
| `--warn` | `#b45309` | `#f0b45a` | врезка «Осторожно» |
| `--ok` | `#15803d` | `#5fd38a` | тесты прошли |
| `--fail` | `#b91c1c` | `#ff7b7b` | тесты упали |
| `--cat-1…8` | категориальная палитра, проверяется на контраст ≥ 3:1 с `--surface` в обеих темах | | сущности в тексте и на графиках |
| `--seq-*`, `--div-*` | последовательная и расходящаяся шкалы для тепловых карт | | матрицы, веса |

Значения стартовые. Контраст текста ≥ 4.5:1 проверяется скриптом.

### Типографика

- Текст: системный шрифт или открытый шрифт с кириллицей (Inter / IBM Plex Sans), подключается локально через `@fontsource`.
- Код: JetBrains Mono или IBM Plex Mono.
- Формулы: KaTeX (свои шрифты).
- Шкала: 14 / 16 / 18 (основной текст) / 22 / 28 / 36. Высота строки текста 1.65.

### Отступы, радиусы, тени

- Шаг 4px: `--space-1` = 4px … `--space-12` = 96px.
- Радиусы: `--radius-sm` 6px, `--radius` 10px, `--radius-lg` 16px.
- Тени мягкие, в тёмной теме заменяются обводкой `--border`.

### Движение

- `--dur-fast` 150ms, `--dur` 250ms, `--ease` cubic-bezier(0.2, 0, 0, 1).

## 4. Компоненты (имена API фиксируются в `docs/ARCHITECTURE.md`)

| Компонент | Назначение |
|---|---|
| `Figure` | обёртка рисунка: номер, подпись, текстовая альтернатива, `figure_id` для заметок |
| `Callout kind="warn|note|tip"` | врезки, включая «Осторожно» |
| `Aside` | сворачиваемое отступление |
| `StepCards` | пошаговые карточки по сложной схеме, синхронизированы с рисунком |
| `Scrolly` | липкий график + шаги текста |
| `Term` | термин глоссария с подсказкой при наведении |
| `Ref` / `DemoLink` | слово в тексте, окрашенное цветом сущности; клик переводит демо в состояние |
| `Level` | блок, видимый с заданного уровня сложности/глубины |
| `CodeLab` | редактор CodeMirror + «Запустить» + рендер `LabResult` |
| `Quiz` | параметризованный вопрос самопроверки (без оценок) |
| `charts/*` | Line, Scatter, Heatmap, Bar, Matrix, Histogram: обёртки D3 на токенах |
| `PrereqGraph` | граф пререквизитов глав |
| `DepthControls` | два слайдера + «Применить» |

## 5. Открытые вопросы

- Скриншоты референсов для сравнения делаются в срезе через Playwright (тексты страниц через fetch почти пустые: сайты рендерятся на клиенте).
- Финальная палитра `--cat-*` подбирается в срезе и проверяется скриптом контраста.

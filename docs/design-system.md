## 3. Принципы

1. **Тёплая выразительная подача.** Бумажный фон, засечные заголовки Literata, насыщенные цвета сущностей. Не «техдока», а хороший журнал.
2. **Воздух.** Колонка текста 700px, большие вертикальные отступы (секция начинается с 64px), широкие рисунки до 1100px.
3. **Цвет несёт смысл.** Каждая сущность главы (Q, K, V) получает цвет из `--cat-*` и сохраняет его в тексте, формулах и графиках. Акцент топика `--topic` меняется тонко: глаз видит, что топик другой, но система одна.
4. **Обзор → детали.** Сначала схема целиком, затем раскрытие частей. Детали сворачиваются или открываются по клику.
5. **Интерактив только по делу.** У каждого интерактива есть подпись «Рис. N», строка «Что заметить» и текстовая альтернатива.
6. **Спокойное движение.** Переходы 150–250 мс, `ease-out`. При `prefers-reduced-motion: reduce` переходы мгновенные, скролл не плавный.
7. **Обе темы равноправны.** Все цвета только токенами; тёмная тема проверяется скриншотами так же, как светлая.

| Группа | Токены |
|---|---|

### Как токены попадают в Tailwind

`tailwind.config.*` читает CSS-переменные, значения не дублируются: `theme.extend.colors` = `{ bg: 'var(--bg)', surface: 'var(--surface)', 'surface-2': ..., border: ..., text: 'var(--text)', muted: 'var(--text-muted)', accent: ..., topic: 'var(--topic)', 'topic-soft': ..., warn, ok, fail, cat: { 1: 'var(--cat-1)', … } }`. Аналогично `fontFamily` (`serif`, `sans`, `mono`), `fontSize`, `spacing` (по `--space-*`), `borderRadius`, `boxShadow`, `transitionDuration`/`transitionTimingFunction`, `maxWidth` (`text`, `wide`). Тёмная тема переключается атрибутом, не классами `dark:`: утилиты `bg-surface` сами меняются вместе с токенами.

## 5. Раскладка

### Центральная ось

Страница главы: сетка из трёх колонок `minmax(0,1fr) minmax(0,var(--text-width)) minmax(0,1fr)`, максимум 1320px, боковые отступы 32px. Колонка текста всегда по центру. Оглавление слева и заметки справа лежат в боковых колонках и **не сдвигают центр**.

| Элемент | Правило |
|---|---|
| Колонка текста | 700px, `font-size` 18px, `line-height` 1.65 |
| Широкий блок (`figure.fig-wide`) | ширина `min(var(--wide-width), 100vw - 48px)`, симметрично по оси (`left: 50%` + `translateX(-50%)`), вертикальные поля 48px |
| Оглавление | слева, sticky `top: 88px`, ширина 160px, отступ от текста 40px; текущий раздел `--topic` + левая полоса 2px |
| Заметка на поле | карточка 240px, справа от текста на 40px, привязана к абзацу-якорю |
| Раздел | `padding-top` 64px, граница сверху между разделами, `scroll-margin-top` 96px; H2 с короткой полосой `--topic` над ним |

### Брейкпоинты (chapter.css)

| Ширина | Поведение |
|---|---|
| ≥ 1181px | три колонки: оглавление, текст, заметки на полях |
| ≤ 1180px | одна колонка текста по центру; оглавление скрыто; заметка уходит в поток под абзац |
| ≤ 900px | колонка на всю ширину с полями 16px; широкие блоки `100vw - 32px`; крошки скрыты; поиск растягивается; H1 34px, H2 26px; навигация между главами в одну колонку |
| ≤ 720px | виджеты перестраиваются (attention-demo), ≤ 760px steps-demo, ≤ 640px lab-demo, ≤ 560px компактный лаб |

Главная: контейнер 1080px, поля 16px (≥ 720px: 32px); сетка карточек топиков 1 колонка, от 640px 2, от 980px 3.

Sticky, высота 56px, фон `--bg` 88% с blur, снизу линия `--border` и полоса прогресса главы 2px цветом `--topic`.

|---|---|

## 6. Изоляция стилей

- Проза (`h2`, `h3`, `p`, `ul`, `ol`, `li`, `code`, `a`) стилизуется только внутри `.prose` и не проникает в `figure`: селекторы вида `:where(.prose) p:not(figure *)`. Нулевая специфичность `:where` оставляет компонентам приоритет.
- Все виджеты стоят в `<figure class="fig-wide">` и сами задают явные `margin`, `padding`, `font`, `list-style`, `background`, `color` для своих элементов. Ничего не наследуют от страницы, кроме токенов.
- Классы виджетов с префиксом (`.lab`, `.kbd-*`, `.topic-*`), без голых тегов вне корня виджета. В Svelte: scoped-стили компонента.
- Свои стили ссылок: в прозе `--accent`, в тексте-ссылке-на-демо `--topic` с пунктирным подчёркиванием.

| `Button` | primary (`--topic`, текст `--surface`), outline (граница `--border`, hover `--topic`), icon-btn 34px; высота 36px | hover, focus-visible, disabled | `.btn-*`, `.icon-btn` |

### Панели LabResult

| Панель | Правила |
|---|---|
| Summary | заголовок «N из M тестов прошли», цвет `--ok`/`--fail` плюс текст и иконка (не только цвет), время запуска |

| Chart | график под тестами (например, веса внимания: ожидание и результат разными `--cat-*`), с легендой и подписями осей |

## 8. Шорткаты

Реализует общий модуль; страница только отдаёт атрибуты-цели. `mod` = `⌘` на macOS, `Ctrl` на Windows/Linux; платформа определяется `navigator.userAgentData?.platform ?? navigator.platform`. `<kbd data-kbd="mod+k">` перерисовывается в `⌘K` или `Ctrl K`; в справке можно переключить нотацию вручную.

| Клавиши | Действие | Цель |
|---|---|---|
| `mod+K`, `/` | поиск | фокус `[data-search]` |
| `?` | справка по шорткатам | модальное окно, `Esc` закрывает |
| `T` | сменить тему | `[data-theme-toggle]` |
| `L` | панель уровней | `[data-levels-toggle]` |
| `[` / `]` | предыдущая / следующая глава | `a[data-prev]` / `a[data-next]` |
| `J` / `K` | следующий / предыдущий раздел | `section[id]` |
| `N` | заметка к выделению | `[data-note-btn]` |
| `M` | отметить пройденным | `[data-mark-done]` |
| `G`, затем `H` | на главную | `a[data-home]` |
| `mod+Enter` | запустить лаб | в редакторе |
| `mod+S` | сохранить черновик лаба | `preventDefault` |
| `mod+Shift+Backspace` | сбросить лаб | с подтверждением |
| `Esc` | выйти из редактора, закрыть панель | везде |

Правила: однобуквенные шорткаты не срабатывают при фокусе в `input`, `textarea`, `[contenteditable]` и с зажатыми модификаторами; справка открывается по `?`; шорткат показывается в `title` и в `kbd` рядом с кнопкой (кроме мобильной версии); тот же шорткат не вешается дважды; в подвале страницы подсказка «Нажмите `?`».

## 9. Графики

- Только токены цвета; сущности в графике того же цвета, что в тексте. Различие не только цветом: форма, подпись, штриховка.
- Оси с подписями и единицами; подписи и тики **12–13px при любой ширине** (не масштабируются вместе с SVG: `viewBox` с реальным размером или пересчёт при ресайзе).
- Легенда обязательна, если серий больше одной; порядок как в данных.
- Тепловая карта: шкала `--seq-0 → --seq-1` с цветовой полосой и подписанными краями; значения в ячейках, если ячеек немного; текст в ячейке контрастен фону (переключается по яркости).
- Под каждым рисунком: «Рис. N. Название», «Что заметить: …», раскрывающаяся «Описание рисунка» (текстовая альтернатива с числами и выводом).
- Интерактив: подсветка по наведению и по фокусу с клавиатуры; значение показывается подсказкой и в тексте рядом.
- На узких экранах график перестраивается (подписи не мельчают, часть данных уходит в таблицу), а не уменьшается.
- Тёмная тема: линии и заливки проверяются отдельно (`--cat-*` светлее).

## 10. Доступность

| Требование | Правило |
|---|---|
| Контраст | текст ≥ 4.5:1; крупный текст (≥ 24px или ≥ 18.66px жирный), значки, линии графиков, границы контролов ≥ 3:1; обе темы, проверяется скриптом по токенам, включая `--topic` на `--surface`/`--topic-soft` и `--cat-*` на `--surface` |
| Не только цвет | статус теста, пройденная глава, сущность дублируются иконкой, текстом или формой |
| Фокус | видимая обводка 2px `--accent`, смещение 2px, на всех интерактивных элементах; порядок фокуса следует визуальному |
| Клавиатура | всё достижимо без мыши; поповер и модальное окно ловят фокус, `Esc` закрывает и возвращает фокус; слайдеры управляются стрелками |
| Движение | `prefers-reduced-motion: reduce`: переходы 0ms, нет плавного скролла, скролли-анимации заменены статичными шагами |
| Семантика | `aria-expanded`, `aria-controls`, `aria-pressed`, `role="dialog"`, `aria-label` у иконок-кнопок, `aria-current` в крошках; формулы с текстовым эквивалентом |
| Размеры | цель клика ≥ 34px; основной текст ≥ 16px |

## 11. Чеклист design-qa

Скриншоты Playwright, обе темы, ширины 1440, 1024, 390; страницы: главная, глава, каждый виджет.

1. Токены: нет «сырых» цветов, шрифтов и отступов; цвета только `var(--...)`.
2. Центральная ось: текст по центру, широкие рисунки симметричны (`min(1100px, 100vw − 48px)`), оглавление и заметки не сдвигают центр; нет горизонтального скролла.
3. Типографика: Literata у H1–H3 и заголовков карточек, Inter в тексте, JetBrains Mono в коде и `kbd`; размеры из шкалы; кириллица без подмены шрифтов.
4. Изоляция: стили прозы не просочились в виджеты (нет лишних отступов, маркеров, цвета ссылок).
5. Тема: обе темы выглядят законченно; тёмная без «серой кашицы», тени заменены обводкой; контраст текста и графиков.
6. Топик: `--topic` меняется тонко и согласованно (полоса, чипы, прогресс, кнопки), не ломает читаемость.
7. Сущности: Q/K/V одного цвета в тексте, формулах, графиках; подсветка `data-hl` работает.
8. Графики: оси, подписи 12–13px, легенда, шкала у тепловой карты, «Рис. N», «Что заметить», альтернатива.
9. Шапка: крошки, поиск, кнопка уровня и поповер (открытый, с «Применить»), тема, прогресс.
10. Состояния: hover, фокус, disabled, пустые и ошибочные состояния лаба, пройдено/не пройдено.
11. Шорткаты: окно справки, нотация macOS/Windows, подсказки на кнопках.
12. Мобильная версия: колонка 16px, перестроенные виджеты, поиск, поповер в экране, цели касания ≥ 34px.
13. Движение и доступность: reduced-motion, видимый фокус, порядок табуляции, `aria-*`.
14. Расхождения с макетом `docs/mockups/shots/` записаны со ссылкой на файл и экран.

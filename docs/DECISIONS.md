# Решения (ответы на вопросы раздела 9 плана)

Дата: 2026-10-16.

| # | Вопрос | Решение |
|---|---|---|
| 1 | Слайдеры | Гибрид: аддитивные слои (`Level` с минимальным уровнем по осям «Сложность» 1–4 и «Глубина» 1–3) + заменяемые блоки (`Variant` для конкретных диапазонов уровней). |
| 2 | Хранение пользовательских данных | IndexedDB локально + синхронизация коммитами через GitHub API в отдельный приватный репозиторий (fine-grained токен только на него). Экспорт/импорт JSON. Агент читает заметки из клона приватного репозитория. |
| 3 | Язык контента | Русский, английские термины при первом упоминании. Код и комментарии в коде на английском. |
| 4 | Compute и torch | Сочетание: браузерные симуляторы + заранее посчитанные бенчмарки; кнопка «Открыть в Colab/Kaggle» со сгенерированным ноутбуком; импорт JSON с результатами внешнего запуска. DL-лабы в браузере на NumPy (Pyodide; torch в Pyodide нет, проверено 2026-10-16, Pyodide 314.0.7). |
| 5 | Порядок | Вертикальный срез: DL Theory → Scaled dot-product attention. Первая волна контента: DL Theory и Classic ML. |
| — | Видимость репозитория | Основной репозиторий пока приватный. GitHub Pages из приватного репозитория требует платного плана; иначе на момент деплоя репозиторий делается публичным. |
| — | Дизайн | Перед реализацией согласуется статический макет (`docs/mockups/`). Между топиками тонко меняется акцент (`--topic`). |

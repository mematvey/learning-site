# Оркестратор

Роль модели в основной сессии. Вызывает субагентов, сам отвечает за результат. Правила: `CLAUDE.md`, раздел «Роль оркестратора» и «Субагенты».

## Когда использовать

Работа из нескольких забот, которые можно вести параллельно или по очереди: компоненты, разделы глав, лабы, макет.

## Что можно и нельзя

- Сам не пишет код фич. Пишет конфигурацию, интеграцию (подключение готовых частей), общие файлы и мелкие правки на стыках.
- Общие файлы трогает только он: `package.json`, lock-файл, `svelte.config.js`, `vite.config.ts`, `tailwind.config.*`, корневые конфиги, `src/routes/+layout.*`, CI, `CLAUDE.md`, `docs/*`, `tasks/*`, `.claude/*`.
- Реестры тем, глав и лабов генерируются сканированием. Руками их не правит никто.
- Не доверяет отчётам субагентов на веру: результат проверяет сам.

## Цикл работы

1. **Нарезка.** Каждый пакет `tasks/<id>.md` по `tasks/TEMPLATE.md`. Проверить, что владеемые файлы пакетов не пересекаются. Если пересекаются: разделить задачу или выстроить по порядку.
2. **Заявка.** `git pull`, посмотреть `tasks/claims/`, создать и запушить `tasks/claims/<id>.claim` до начала работы (протокол в `docs/LANES.md`).
3. **Worktree.** `git worktree add -b task/<id> .worktrees/<id> main`. Субагенту передать абсолютный путь к worktree.
4. **Запуск.** Субагенты запускаются в фоне (`run_in_background`), несколько сразу, если нет конфликтов файлов.
5. **Не простаивать.** Пока идут задачи, готовить следующие пакеты и проверять завершённые. Не опрашивать в цикле: ждать уведомлений о завершении.
6. **Проверка.** Сам в worktree запускает `npm run check` (когда появится) и `uv run ruff check`. Визуал: скриншоты и оценка `design-qa`. Контент: факты и уровни проверяет `verifier`. Важные пакеты проверяет агент, не видевший процесс написания.
7. **Слияние.** По одному, в порядке зависимостей, после зелёных проверок. Перед слиянием ребейз на `main`. После слияния удалить worktree, ветку и заявку.

## Провал и частичный результат

- Субагент вернул `partial`: если осталось 10–20k токенов работы, доделать (SendMessage тому же агенту или коротким пакетом). Если больше, выдать остаток отдельным пакетом.
- Пакет провален дважды: разбить мельче, а не повторять прежний.
- Отчёт субагента читается по `tasks/REPORT-TEMPLATE.md`; фиксировать открытые вопросы и решать их до слияния.

## Git

- Сообщения коммитов на английском, Conventional Commits (`feat(levels): ...`).
- В коммитах, описаниях PR, ветках и комментариях не упоминать агентов, ИИ, Claude или модели. Никаких `Co-Authored-By` с моделями.

# Автор лаба

Создаёт один лаб. Правила: `CLAUDE.md` (пути и id лабов), `docs/plan.md` (лабы в браузере на NumPy через Pyodide), `docs/DECISIONS.md` (решение 4: torch в Pyodide нет).

## Когда использовать

Один лаб по пакету: одна функция или один алгоритм, одна папка `labs/<lab-id>/`. Главу с лабом писать другой ролью.

## Что можно и нельзя

- Трогает только `labs/<lab-id>/` из пакета и, если пакет разрешает, Python-тесты эталонов.
- Не трогает главы (`content/`), компоненты, раннер лабов, конфиги, `docs/*`, реестры.
- Не добавляет зависимости сверх NumPy и того, что пакет перечисляет.
- Не использует torch: DL-лабы на NumPy.

## Состав лаба

- `lab.yaml`: id, название, уровень, входы и выходы, ссылка на главу.
- `starter.py`: стартовый код с `# TODO` в нужных местах, без готового решения.
- `solution.py`: эталон.
- `tests_visible.py`: тесты, которые видит студент (мелкие, с понятными сообщениями).
- `tests_hidden.py`: тесты, которые студент не видит (граничные случаи, масштаб, маска).
- Результат запуска тестов описывается структурой `LabResult` из пакета (сводка, список тестов, время, ошибки с ожидаемым и полученным значением).

## Как работать

1. Читать пакет `tasks/<id>.md` и примеры, указанные в нём. Примеры для копирования: существующий лаб в `labs/`, если он есть в пакете.
2. Работать только в своём worktree по абсолютному пути из пакета.
3. Написать эталон, потом тесты, потом старт. Старт должен падать на тестах, а эталон проходить.
4. Тесты детерминированные: фиксированный seed, допуски в `1e-6` или как в пакете.
5. Запуск проверок только через `uv run` (например, `uv run --with numpy pytest labs/<lab-id>`). Команды из пакета выполнять как написано.
6. Бюджет из пакета. Упёрся в лимит: остановиться и вернуть частичный результат. Осталось 10–20k: доделать.

## Windows и окружение

- Bash-инструмент это Git Bash. Python только через `uv`, никакого глобального `pip`.
- Пути в тестах не зависят от ОС: использовать `pathlib`.
- Линтер: `uv run ruff check labs/<lab-id>` должен проходить.
- `cd` между вызовами не сохраняется.

## Критерии готовности

- `uv run pytest` на эталоне: все тесты проходят.
- На старте: тесты падают (ожидаемо), и это видно в отчёте.
- `uv run ruff check` для лаба проходит.
- Нет правок вне пакета.

## Отчёт

Формат `tasks/REPORT-TEMPLATE.md`, до 200 слов: что проходит на эталоне, что падает на старте, сколько тестов.

## Коммит

Сообщение точно из пакета. Без `Co-Authored-By`, без упоминаний агентов, ИИ и моделей.
